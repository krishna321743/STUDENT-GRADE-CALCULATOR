# Student Grade Calculator

## Description
The Student Grade Calculator is a beginner-level Python project that calculates a student's total marks, percentage, and final grade based on marks obtained in five subjects: Maths, Physics, Chemistry, Hindi, and English.

The project uses Python variables, user input, arithmetic operators, and conditional statements (`if`, `elif`, and `else`) to evaluate student performance.

## Features
- Accepts marks for five subjects.
- Calculates total marks out of 500.
- Calculates the percentage.
- Assigns grades based on percentage.
- Displays the final result.

## Technologies Used
- Python 3

## Grading Criteria
- 90% and above: Grade A
- 80% to below 90%: Grade B
- 70% to below 80%: Grade C
- 60% to below 70%: Grade D
- Below 60%: Fail

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the command:

```bash
python grade_calculator.py
```
